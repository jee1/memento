# Phase 1 Data Model: 벡터 유사도 절대 척도 복원 (#806)

**Date**: 2026-08-29 | **Plan**: [plan.md](./plan.md)

**저장 스키마 변경 없음.** 이 문서는 데이터베이스 스키마가 아니라 검색 경로를 흐르는 **런타임 값 객체**와 그 값이 지켜야 하는 규칙을 정의한다. Principle III(스키마·마이그레이션 규율)는 해당 사항이 없다.

## 1. 코사인 거리 (cosine distance)

| 항목 | 값 |
|------|-----|
| 출처 | `vec0` 가상 테이블(`distance_metric=cosine`)의 `distance` 컬럼 |
| 범위 | [0, 2] |
| 방향 | **작을수록 가깝다** |
| 특수값 | 부동소수 오차로 음수가 나올 수 있다. 비유한값이 올 수 있다 |

**규칙**: 이 값은 저장소 경계를 넘어 상위 계층으로 그대로 전달되지 않는다. 반드시 §2로 변환된 뒤에만 노출된다.

## 2. 벡터 유사도 (vector similarity)

| 항목 | 값 |
|------|-----|
| 정의 | `clamp(1 − cosine_distance, 0, 1)`. 비유한 입력은 0 |
| 범위 | [0, 1] |
| 방향 | **클수록 가깝다** |
| 결과셋 의존성 | **없음.** 같은 기억·같은 쿼리·같은 제공자면 결과셋 구성과 무관하게 동일한 값 |

**규칙**:
- R2-1. 변환 정의는 저장소 전체에 하나만 존재한다(FR-020).
- R2-2. 결과셋의 최소·최대에 의존해 다시 늘리지 않는다(FR-001, FR-002).
- R2-3. 후보가 1건이든 여러 건이든 같은 값이다(FR-004).
- R2-4. 반환 직전 값은 항상 [0, 1]의 유한값이다(FR-012, FR-017).

## 3. 벡터 검색 결과 항목 (vector search result)

근접도를 나타내는 필드는 **하나뿐**이다(FR-024).

| 필드 | 의미 | 비고 |
|------|------|------|
| 식별자 | 기억 ID | |
| 근접도 | §2의 벡터 유사도 | 방향이 다른 대체 필드를 함께 두지 않는다 |
| 내용·유형·중요도·시각·태그 | 표시·랭킹용 메타데이터 | 이번 변경과 무관 |
| 범위 속성(프로젝트·소유자·프로세스·세션) | 격리 필터 결과 | 구성 변경 금지(FR-022) |

**상태 전이 없음.** 결과 항목은 질의 시점에 만들어지고 소비된 뒤 버려진다.

## 4. 벡터 후보 풀 (candidate pool)

임계값 판정과 보충을 거쳐 결합 단계로 넘어가는 묶음.

| 단계 | 규칙 |
|------|------|
| 원시 후보 | 제공자별 프리페치 결과 |
| 임계값 통과 | 절대 유사도 ≥ 하이브리드 벡터 임계값. **재조정보다 먼저 수행**(FR-005) |
| 보충 | 통과분이 요청 수에 못 미치면 원시 후보에서 유사도 내림차순으로 채운다. 채워진 후보도 자기 절대 점수를 유지(FR-006) |
| 중복 제거 | 같은 기억이 여러 제공자에서 나오면 절대 유사도의 최댓값을 남긴다(FR-007) |

**불변식**: 어느 단계에서도 다른 후보의 존재가 특정 후보의 점수를 바꾸지 않는다. 바꾸는 것은 **포함 여부와 순서**뿐이다.

## 5. 경로별 조회 범위

| 경로 | 조회 제공자 | 비고 |
|------|-------------|------|
| 정상 경로 | 저장된 모든 제공자(병렬) | 중복 제거에서 제공자 중 최댓값 채택 |
| 대체 경로 | 쿼리 임베딩이 사용한 제공자 1개 | 벡터 인덱스를 쓸 수 없을 때 진입 |

**규칙**: 두 경로는 **같은 척도**를 따른다(FR-011). 조회 범위 차이는 설계된 차이이며 척도 불일치가 아니다. 경로 간 점수 비교는 제공자를 맞춘 뒤에 한다(SC-010).

## 6. 랭킹 버전 식별자 (ranking version)

| 항목 | 현재 구성 | 변경 후 |
|------|-----------|---------|
| 해시 입력 | 랭킹 가중치, 하이브리드 벡터 임계값, 프리페치 배수, 보충 활성 여부 | **+ 점수 척도 규정** |

**규칙**: 점수 산출 방식이 달라지면 식별자도 달라진다(FR-023). 값의 재튜닝이 아니라 구성 항목의 추가다.

## 7. 저장된 점수 스냅샷

| 항목 | 처리 |
|------|------|
| 피드백·품질 텔레메트리에 저장된 점수 구성 | 마이그레이션·백필 없음 |
| 척도 혼재 | 기준 문서의 시점 기록과 §6의 식별자 변경으로 구분한다 |
| 랭킹 입력 여부 | 아니다. 분석용이며 검색 동작에 영향이 없다 |
