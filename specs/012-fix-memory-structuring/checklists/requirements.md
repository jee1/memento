## 비고

- SC-001~SC-007이 각 사용자 스토리의 수용 시나리오에 직접 매핑됨
- 가정 섹션에 선택된 임계값(클러스터 크기=2, 유사도=0.65/0.85)이 명시되어 이해관계자 검토 가능
