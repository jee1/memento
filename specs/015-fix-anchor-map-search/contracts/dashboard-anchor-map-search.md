# Contract: 대시보드 앵커 맵 · 검색 후 UI 동작

**범위**: 브라우저에서 `POST /tools/search_local`(또는 동일 프록시)이 **성공(2xx)** 하고 본문에 `items` 배열이 있을 때, 앵커 맵 정적 스크립트가 만족해야 하는 동작.

## 불변

- MCP `search_local` 도구의 **입력/출력 JSON 스키마**는 변경하지 않는다.

## 클라이언트 동작 (본 픽스 후)

1. 검색 성공 후 **`nodes`가 비어 있거나 맵이 아직 그려지지 않은 경우**, 스크립트는 **예외를 throw하지 않는다**.
2. 위 조건에서 맵 포커스·줌·`nodes.find` 기반 이동은 **생략**할 수 있다; 검색 결과 목록/로그 등 다른 UI는 스펙대로 유지.
3. 맵에 렌더된 노드가 있고 검색 결과 ID가 맵에 존재하면, **수정 전과 동등한 수준**으로 하이라이트·선택·(기존과 같은) 줌 시도가 가능해야 한다.

## 비범위

- 검색 API 실패(4xx/5xx), 네트워크 오류, 빈 `items`에 대한 UX는 본 계약의 필수 항목에서 제외(스펙 Out of Scope와 정합).
