# Quickstart: 013-refactor-approach program

**Audience**: Contributors and reviewers working on **production maintainability** refactors for Memento.

## 1. Before you code

1. Read **`spec.md`** — scope, FR-013/FR-026 gates, first-wave constraints (parity, no schema).
2. Read **`maintainer-map.md`** — which subsystem owns which concern (update it when your increment merges).
3. Confirm **integration line** in **`plan.md`** (default **`main`**).

## 2. Local quality gates (required before merge)

From repository root:

```bash
npm run lint
npm run type-check
npm test
```

These satisfy constitution **IV** and FR-013 **CI** requirement.

## 3. When is manual regression mandatory? (FR-013)

Complete the authoritative checklist at:

`specs/013-refactor-approach/manual-regression-checklist.md` (repository root)

**Mandatory before merge** only if your increment **directly** changes **runtime behavior or request-handling paths** in:

- Memory **recall** (MCP/agent flows),
- **Hybrid search** execution,
- **Administrative HTTP** routes.

**Not** mandatory at program level for: documentation-only; type-only / emit-equivalent (FR-026); changes **only** in other capability areas (embedding, background scheduling, relationship extraction) **without** direct edits to the three surfaces—**CI still required**; manual steps **recommended**.

**Emergencies**: FR-019 — org policy may differ.

## 4. Useful scenario commands

Depends on what you touched—examples from root `package.json`:

- Search: `npm run test:search`
- Forgetting/TTL: `npm run test:forgetting`
- HTTP/MCP client smoke: `npm run test:client`
- Batch scheduler: `npm run test:batch-scheduler`

Use the **manual-regression-checklist** for the agreed cross-cutting pass.

## 5. Documentation duties

- Update **`maintainer-map.md`** (increment map + boundaries) when your PR lands.
- Add **FR-011** operational touchpoints in PR description or linked notes (logs/metrics/alerts or “none”).

## 6. Where to record program decisions

| Topic | Location |
|--------|----------|
| Integration line | `plan.md` |
| Checklist authority | `plan.md` + `manual-regression-checklist.md` |
| SC-002 measurement rules | `research.md`, detailed in `maintainer-map.md` |

## 7. Next step

Break work into **`tasks.md`** via **`/speckit.tasks`** (not generated by `/speckit.plan`).
