# Contract: Environment Configuration Consistency

## Purpose

환경변수 템플릿과 실제 사용 규칙의 정합성을 유지하기 위한 계약을 정의한다.

## Contract Rules

1. 공통 변수는 루트 `env.example`에 정의되어야 한다.
2. 동일 의미 변수는 하나의 템플릿에만 정의되어야 하며, 불가피한 별칭은 전환 기간 동안만 허용하고 우선순위를 명시해야 한다.
3. 보안 민감 변수는 프로덕션 필수 여부를 주석으로 명시해야 한다.
4. 비보안 권장 설정이 아닌 위험 옵션은 경고 주석이 필수다.
5. 변수명 변경 시 이전 이름과의 호환 또는 전환 안내가 있어야 한다.

## Validation Checklist

- 템플릿 파일 간 의미 중복 변수 0건
- 필수 보안 변수의 필수 표기 누락 0건
- 템플릿 주석과 파일명 역할 불일치 0건
