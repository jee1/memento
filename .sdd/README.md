# Spec-Driven Development (SDD)

이 디렉터리는 **Spec-Driven Development** 스킬(LobeHub: `moonklabs-aiwf-spec-driven-development`)용 워킹 디렉터리입니다.

## 사용법

| 단계 | 트리거 | 결과 |
|------|--------|------|
| 1. 명세 | `specify: [기능 설명]` | `specs/NNN-feature/spec.md` |
| 2. 계획 | `plan: [기술 스택]` | `plan.md`, `data-model.md` |
| 3. 태스크 | `tasks` | `tasks.md` |
| 4. 구현 | `implement` | 소스 코드 |

스킬 상세: `~/.cursor/skills/moonklabs-aiwf-spec-driven-development/SKILL.md` (전역 설치)

## 디렉터리 구조

```
.sdd/
└── specs/           # 기능별 명세 (001-feature-name/, 002-.../)
docs/plans/          # Superpowers 실행용 계획 문서
```
