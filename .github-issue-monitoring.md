## 🔄 마이그레이션 단계

1. **디렉토리 생성**
   ```bash
   mkdir -p src/domains/monitoring/{services,tools}/__tests__
   ```

2. **파일 이동** (git mv 사용)
   - Services 파일 이동
   - Tools 파일 이동

3. **Import 경로 업데이트**
   - 도메인 내부 import 경로 수정
   - 다른 도메인에서 참조하는 import 경로 수정
   - Monitoring tools는 HTTP API로만 제공되므로 `src/tools/index.ts`에는 영향 없을 수 있음

4. **테스트 실행**
   ```bash
   npm test -- src/domains/monitoring
   ```

5. **검증**
   - 모든 테스트 통과 확인
   - TypeScript 컴파일 오류 확인
   - Lint 오류 확인

## ⚠️ 주의사항

- Monitoring 서비스는 다른 도메인에서 광범위하게 사용될 수 있으므로 import 경로 수정 범위가 큼
- Performance monitoring은 시스템 전반에 걸쳐 사용되므로 의존성 확인 필요
