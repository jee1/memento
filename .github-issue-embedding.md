## 🔄 마이그레이션 단계

1. **디렉토리 생성**
   ```bash
   mkdir -p src/domains/embedding/{services,providers,tools}/__tests__
   ```

2. **파일 이동** (git mv 사용)
   - Services 파일 이동
   - Providers 파일 이동
   - Tools 파일 이동

3. **Import 경로 업데이트**
   - 도메인 내부 import 경로 수정
   - 다른 도메인에서 참조하는 import 경로 수정
   - `src/tools/index.ts` 업데이트

4. **테스트 실행**
   ```bash
   npm test -- src/domains/embedding
   ```

5. **검증**
   - 모든 테스트 통과 확인
   - TypeScript 컴파일 오류 확인
   - Lint 오류 확인

## ⚠️ 주의사항

- Embedding 서비스는 많은 도메인에서 사용되므로 import 경로 수정 범위가 큼
- Provider factory 패턴 사용처 확인
- `src/tools/index.ts`에서 migrate-embeddings-tool export 경로 수정 필요
