# How to check anchor connections

Ways to inspect which memories are linked to anchors.

## 1. Anchor Map UI

Use the Anchor Map UI to visualize and inspect anchor–memory links.

## 2. API

Use the relation/anchor admin APIs to list connections programmatically.

## 3. MCP tool

Use the MCP tools that expose anchor and relation data.

## 4. Database

Query the relevant tables (e.g. `anchor`, `memory_relation`) directly.

For detailed steps and examples, see the [Korean version](../ko/how-to-check-anchor-connections.md).
