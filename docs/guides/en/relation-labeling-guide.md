# Relation labeling guide

This document provides relation-type criteria, confidence ranges, and labeling examples for the Memento relation extraction engine.

## Relation types (overview)

Memento supports six relation types: `CAUSES`, `DEPENDS_ON`, `PRECEDES`, `CONTEXT_OF`, `SIMILAR_TO`, `CONTRASTS`.

For full criteria, confidence ranges, examples, and checklists, see the [Korean version](../ko/relation-labeling-guide.md).
