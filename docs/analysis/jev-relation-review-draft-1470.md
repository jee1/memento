## 판정·애매한 쌍 처리 기준

- source는 새로 저장한 기억, target은 기존 기억이다. 저장 시각으로 사건의 순서를 추정하지 않는다.
- CAUSES: source의 사건이 target 사건의 원인. DEPENDS_ON: source의 실행에 target이 필수. FOLLOWS: source 사건이 같은 구체적 작업 흐름의 target 사건 뒤에 발생한다. FOLLOWS에 인과를 요구하지 않는다.
- CONTRASTS_WITH: 같은 대상·같은 비교 축의 다른 주장·조건·선택지. 의미는 대칭이며 출력 source→target이나 반대 방향 모두 의미상 정답이다. 현재 단일 방향 실행에서는 요청 source→target으로 저장되는지 따로 검사한다.
- REFERENCES: source가 target 문서·기록을 명시적으로 인용하거나 가리킨다. 내용 중복만으로 참조를 추정하지 않는다. BELONGS_TO: 부분 source→전체 target. 동급 구성 요소끼리는 포함 관계가 아니다.
- 동시 성립이 명백하면 정답 종류 집합으로 표현한다. 이 초안은 직접 인과를 단순 선후보다, 필수 전제를 선택적 참고보다 우선하며 각 양성에 한 종류를 제안한다. 복수 종류가 필요한지 사람 검토에서 확정한다. 결과를 본 뒤 정답을 유리하게 넓히지 않는다.
- 식별 맥락·순서·대조 축이 부족하면 `ambiguous`로 둔다. 동급 작업·명시적 참조 없는 중복도 해당한다. 무관으로 강제하지 않고 모든 주 지표 분모에서 제외한다. 애매 사례의 채택·거절·오류는 별도 개수로 보고한다. 동급 amb01·amb02는 전체 정답을 보류하되 `forbidden_types`로 CONTRASTS_WITH·BELONGS_TO 금지를 제안한다. 이 별도 제약도 사용자 검토 대상이다.
- 같은 저장소·시각·공통 단어만 공유하고 독립 대상·업무임이 명시되면 `unrelated`. 관계 6종을 모두 거절해야 정답이다. 같은 일의 맥락 통과만으로 특정 종류가 성립하지 않는다.
- 원인·의존·참조·포함의 반대 방향은 오답이다. FOLLOWS도 후속→선행만 정답이다. 각 source 기억 타입에서 정답 종류가 허용되는지 기존 `MEMORY_TYPE_RELATION_MAP`으로 검사한다.
- 사용자는 각 행의 종류·방향·이유·애매 여부를 수정하거나 승인한다. 개별 검토 기록·검토자·시각 없이 `reviewed`로 바꾸지 않는다. 단순 진행 승인을 사람 gold로 승격하지 않는다. 이번 PR은 계속 `pending`이다.

## 사전 등록 제안 v1 — 새 집합 결과 열람 전

이 수치는 **검토 전 제안**이다. 검토 후, 모델 출력 열람과 후속 구현 전에 수치·fixture SHA·기준선 commit·실행 코드 SHA·모델 버전·평가 실행 순서를 고정한다. 현재 초안 SHA-256: `cdfeac5a75d49170ad3c43dc3542f3c4404463e5bd48a5f28867a7b924be9545`. 본 단계는 새 집합 모델 결과를 만들지 않는다. 이전 28쌍의 결과로 새 집합 기준선을 대체하지 않는다.

`B`는 현재 main의 기준선, `C`는 이후 승인된 수정안이다. 같은 고정 집합·모델·호출 배치 크기 1·source→target 방향으로 비교한다. 종류·방향 모두 맞아야 TP다. 오류·거절·잘못된 종류는 참 관계 누락으로 센다. 모델 오류를 정상 거절로 세지 않는다. 모든 비율은 분자/분모와 함께 보고한다.

| 지표 | 분모·정의 | 제안 목표·허용 회귀 폭 |
|---|---|---|
| 종류별 정밀도 P(t) | 해당 종류로 채택한 수 중 정답 종류·방향 일치 수 | FOLLOWS·CONTRASTS_WITH 각각 ≥0.80, B 대비 하락 0. 나머지 4종은 B 대비 최대 0.05 하락, 각 종류의 올바른 채택 수 감소 0. 예측 0건이면 미정(null)이며 통과 불가 |
| 두 대상 종류의 잘못된 채택 | FOLLOWS 또는 CONTRASTS_WITH로 채택했으나 정답과 다른 수 | B에 오류가 있으면 합계 최소 1건 감소, B가 0이면 C도 0 |
| 무관 쌍 연결률 U | 무관 중 관계를 채택한 수 / 전체 무관 수(현재 8) | ≤0.125(최대 1/8), B 대비 증가 0. B>0이면 최소 1건 감소 |
| 채택 중 무관 비율 | 무관에 채택한 수 / 모든 채택 수 | B 대비 증가 0. 채택 0건은 미정이며 통과 불가 |
| 참 관계 누락률 FN | 거절·종류/방향 오류·호출 오류로 놓친 참 관계 / 전체 참 관계(현재 34) | 전체 ≤0.15이며 B 대비 증가 0. 각 종류 누락률 증가 0 |
| 정상 거절률 R | 오류 없이 관계 없음 반환 / 주 지표 대상(현재 42) | B 대비 증가 ≤0.10, 절대값 ≤무관 비중(8/42)+0.15. FN·커버리지 조건도 동시에 충족 |
| 양성 커버리지 | 종류별 올바른 채택 수 / 해당 종류 참 관계 수 | 모든 종류 ≥0.80. 전부 거절, 한 종류 전부 누락, 정밀도만 오른 변경 모두 탈락 |
| 동급 사례 금지 종류 채택 | amb01·amb02에 CONTRASTS_WITH 또는 BELONGS_TO를 채택한 수 / 두 사례 | 0/2. 주 지표에서 애매 사례를 제외해도 이 별도 필수 게이트로 동급 오분류를 배제한다 |
| 호출 오류율 | 오류 수 / 주 지표 대상 | 0. 오류 사례를 삭제하거나 분모에서 빼지 않는다 |

소표본이라 비율 한 건의 변화가 크다. 정밀도 분모는 예측 수라 사전 고정되지 않으며 백분율과 원시 개수를 함께 본다. 전체 조건과 동급 사례 별도 게이트를 AND로 적용한다. 기존 평가기의 집계는 애매 사례를 제외하므로, 이 별도 게이트는 실행 snapshot의 raw results를 ID로 대조해 판정한다. 기존 집계 통과만으로 최종 통과를 선언하지 않는다. 동급 사례 두 raw result가 모두 존재하고 `status=ok`여야 별도 게이트를 판정한다. 오류·미실행은 통과 불가다. 애매 사례를 결과 확인 후 분모로 이동하거나 어려운 쌍을 제거하면 새 실험으로 다시 등록한다. 기준선을 측정했는데 이미 목표를 충족하면 개선을 주장하지 않고, 오류가 재현되는 합성 사례를 별도 등록한 뒤 사용자 검토를 받는다. 기준을 낮춰 통과시키지 않는다.

후속 비교는 동일 고정 모델로 B/C 한 묶음을 완료하고 C를 한 번 독립 재호출한다. 두 C 실행 모두 기준을 만족해야 한다. 날짜·모델별 실제 호출(재시도 포함)을 호출 전에 장부에 기록하고 **하루 20회**를 넘기지 않는다. 두 라운드 × B/C 각 1회라 단일 쌍 비교에 최대 4회: 다른 사용량이 없을 때도 하루 최대 5쌍, 재시도 발생 시 더 적게 실행한다. 반복 C는 별도 날짜 예산을 쓴다. 장기 비교의 모델 별칭 변동·날짜 효과를 기록하며 모델이 바뀌면 비교를 중단한다. 예산 소진을 오류나 거절로 채점하지 않고 미완료로 남긴다. 현재는 `pending`이라 모델 실행을 시작하지 않는다.

## 재현 테스트의 증거와 한계

[공유 경로 테스트](../../packages/memento-core/src/domains/relation/services/__tests__/jev-relation-judge-failure-modes.spec.ts)는 실제 `JevRelationJudge.judge`를 호출한다. 외부 모델만 mock한다.

1. 맥락 실패: 무관한 시간 인접 쌍 `unrel01`에 합성 relevance=0.9와 FOLLOWS=0.9를 주입하면 잘못된 edge가 반환된다. relevance=0.49 대조군은 type round 전에 중단한다.
2. 종류 실패: 중복 `dup01`, 실제 후속 `follow01`, 동급 `amb01`에 CONTRASTS_WITH를 최고 점수로 주입하면 그대로 선택된다. 정답 점수 대조군은 REFERENCES와 인과 없는 FOLLOWS를 보존한다. 이는 점수 선택·전파의 특성화이며 **모델이 실제로 그 점수를 출력했다는 증거가 아니다**. amb01의 대조 아님은 후보 기준이며 최종 정답 거절 여부는 사람 검토를 기다린다.
3. 현재 경로의 구조적 정보 손실: 서로 다른 맥락/종류 쌍 앞에 같은 200자 합성 접두사를 붙이면 실제 모델 요청 두 개가 완전히 같아진다. 식별 증거가 절단 경계 뒤에 있으면 구별할 입력 자체가 사라진다. 이 경계 사례는 결정론적으로 재현되지만 #1466 운영 오류의 원인 비중은 측정하지 않았다. 절단 길이·후보 풀은 변경하지 않는다.

기존 166쌍의 점수 원자료를 공개 집합으로 복제하지 않았다. 실제 Jev 의미 오판의 현재 재현·발생 빈도는 **미검증**이며 합성 점수 테스트를 의미 정확도 결과로 사용하지 않는다. 테스트는 통과하는 특성화 방식이며 실패 테스트를 숨기기 위한 `it.fails`는 쓰지 않는다.

[초안 경계 테스트](../../scripts/jev-relation-review-draft.spec.ts)는 타입별 허용 종류·방향·분모와 `pending`의 실행 거절을 검사한다. 전부 거절된 출력은 FN=1, 양성 커버리지=0, 종류 정밀도=null이라 위 기준에서 탈락한다.
