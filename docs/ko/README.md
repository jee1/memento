# 한국어 문서 (docs/ko)

`docs/ko/`는 특정 주제에 집중된 한국어 가이드를 두는 경로입니다. 이 디렉터리는 주제별로 독립된 문서를 모아 두며, 더 광범위한 범주의 문서는 각각의 전용 경로를 사용합니다. 범용 가이드는 [guides/ko/](../guides/ko/), API 레퍼런스는 [api/ko/](../api/ko/), 운영 절차는 [operations/ko/](../operations/ko/)를 참고하세요.

## 데모·시연

현재 이 디렉터리에는 Memento의 기억 진화 메커니즘을 시각적으로 보여 주는 데모 문서가 있습니다. [evolution-demo.md](evolution-demo.md)는 기억이 시간의 흐름에 따라 어떻게 변형되는지를 세 가지 시나리오(시간 경과에 따른 답변 변화, 망각 정책 비교, Episodic → Semantic 통합)로 설명합니다. 로컬에서 재현하는 방법과 발표·시연을 위한 권장 흐름도 함께 담고 있습니다. 이슈 [#346](https://github.com/jee1/memento/issues/346)에서 배경을 확인할 수 있습니다.

전체 문서 포털은 [docs/README.md](../README.md)를 참고하세요.
