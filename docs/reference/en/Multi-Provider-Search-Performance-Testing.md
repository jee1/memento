# Multi-provider search performance testing

Hybrid search in Memento blends FTS5 and multiple vector providers. Performance depends on corpus size, active providers, and hardware—so changes to ranking or embedding should be validated with repeatable benchmarks rather than gut feel.

The full methodology (fixture setup, scenarios, metrics tables, and historical runs) lives in the [Korean version](../ko/Multi-Provider-Search-Performance-Testing.md). Use it when comparing providers or before rolling out ranking coefficient changes.
