# PRD: Vector search stability (2025-10)

This PRD captured stability goals for vector search—consistent dimensions, safe provider failover, and predictable recall when embeddings are missing or stale. It informed ranking guards and admin diagnostics that shipped in later releases.

For requirements, acceptance criteria, and the original timeline, see the [Korean version](../ko/prd-vector-search-stability-2025-10.md). Treat that file as the source of truth; this page exists so English readers can find the PRD without guessing the Korean path.
