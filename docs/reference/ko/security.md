# 보안 참고 (Security Notes)

## HTTP API 인증·인가

- **현재 상태**: HTTP 서버(`/tools/*`, `/api/*`, `/admin/*`, `/quality/*` 등)에는 **인증·인가 미들웨어가 없습니다.** `req.toolContext`만 검사하며, 네트워크에 노출된 경우 누구나 기억 조회·삭제·관리 API를 호출할 수 있습니다.
- **권장 사용**: **내부망 전용** 또는 **MCP 클라이언트 전용**으로 사용하세요. 공용 네트워크에 HTTP 서버를 노출하지 마세요.
- **운영 환경**: 공용에 노출할 경우 API 키, JWT 등 **인증 미들웨어**를 도입하고, 관리/삭제 엔드포인트에는 **역할 기반 접근 제어**를 적용하는 것을 권장합니다.
- **CORS**: `CORS_ALLOWED_ORIGINS` 환경 변수로 허용 오리진을 제한할 수 있습니다. 비어 있으면 크로스 오리진 요청을 허용하지 않습니다.
