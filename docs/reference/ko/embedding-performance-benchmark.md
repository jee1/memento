# 임베딩 서비스 성능 벤치마크 결과

## 개요

Memento 프로젝트의 4가지 임베딩 제공자에 대한 성능 벤치마크 결과입니다.

## 벤치마크 환경

- **CPU**: Intel/AMD x64
- **메모리**: 8GB+
- **Node.js**: v20+
- **테스트 데이터**: 10개 텍스트 샘플
- **측정 항목**: 속도, 메모리 사용량, 성공률

## 성능 결과 요약

| 제공자 | 성공률 | 평균 속도 | 메모리 사용량 | 차원 | 비용 |
|--------|--------|-----------|---------------|------|------|
| **TF-IDF** | 100% | 0.82ms | 4.48MB | 512 | 무료 |
| **MiniLM** | 100% | 56.50ms | 47.07MB | 384 | 무료 |
| **통합** | 100% | 91.34ms | 25.91MB | 384 | 무료 |

## 상세 분석

### TF-IDF 제공자
- **속도**: ⚡ 극도로 빠름 (0.82ms)
- **메모리**: 💾 매우 효율적 (4.48MB)
- **정확도**: 📊 키워드 기반 매칭
- **추천 용도**: 대량 처리, 실시간 검색

### MiniLM 제공자
- **속도**: 🎯 균형잡힌 성능 (56.50ms)
- **메모리**: 📈 중간 수준 (47.07MB)
- **정확도**: 🧠 의미 이해 능력
- **추천 용도**: 일반적인 AI Agent 용도

### 통합 서비스
- **속도**: 🔄 폴백 처리로 인한 오버헤드
- **메모리**: 📊 여러 서비스 관리
- **정확도**: 🎯 최적 제공자 자동 선택
- **추천 용도**: 프로덕션 환경

## 선택 가이드

### 속도 우선
**TF-IDF** - 0.82ms로 가장 빠름

### 정확도 우선
**MiniLM** - 의미 이해 능력과 속도의 균형

### 안정성 우선
