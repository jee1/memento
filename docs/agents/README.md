# 에이전트 가이드 (상세)

[AGENTS.md](../../AGENTS.md)는 저장소 전체의 짧은 진입점이고, 이 폴더는 **일상 작업에 필요한 깊이**를 담습니다. 코드를 고치기 전에 구조를 파악하려면 [architecture.md](./architecture.md)부터, 명령이나 Docker·DB 절차가 필요하면 [commands.md](./commands.md)로, MCP·graphify·기술 부채·대시보드 습관은 [agent-workflow.md](./agent-workflow.md)를 보면 됩니다. recall 점수가 왜 그렇게 나오는지 알고 싶다면 [search-ranking.md](./search-ranking.md)가 공식을 설명합니다.

코딩 표준과 PR 규칙은 [DEVELOPMENT_RULES.md](../../DEVELOPMENT_RULES.md)에 있습니다. 문서를 새로 쓰거나 고칠 때는 [docs/docs-classification.md](../docs-classification.md)의 **네러티브 문체** 지침을 따르는 것을 권장합니다.
