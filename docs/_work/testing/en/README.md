# Testing documentation (English)

Memento’s quality work spans **unit specs in `packages/`**, **search-quality benchmarks** under `tests/fixtures/`, and **manual run notes** in this `_work/testing/` tree. Most step-by-step harness guides are maintained in Korean because day-to-day contributors use them in Korean-first reviews.

If you are validating consolidation or sleep-merge behavior, start with the [consolidation quality testing guide (KO)](../ko/consolidation-quality-testing.md). For agent smoke matrices and release gates, see [operations/agent-smoke-matrix.md](../../../operations/ko/agent-smoke-matrix.md) and [agent-integration-release-gate.md](../../../operations/ko/agent-integration-release-gate.md). New English pages here should follow the same narrative tone as [docs-classification.md](../../../docs-classification.md)—context first, then commands.
