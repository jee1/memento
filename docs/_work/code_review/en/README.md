# Code reviews (English)

This folder holds **pre-merge review requests** and reviewer notes tied to specific issues or features. Most write-ups are in Korean because day-to-day reviews run in that language; the English README orients you to where those files live and how they relate to SDD folders under `_work/plans/`.

For the full list, open the [Korean code reviews](../ko/) directory. When you add a new review, follow the narrative tone in [docs-classification.md](../../../docs-classification.md)—state context and decision first, then checklist items.
