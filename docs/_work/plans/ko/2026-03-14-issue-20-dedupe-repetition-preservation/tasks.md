### T2: 병합 시 num_times·last_mentioned_at 갱신 로직

| 항목 | 내용 |
|------|------|
| **목표** | 유사 기억 그룹을 병합할 때, 대표 항목에 num_times 누적(또는 = N), last_mentioned_at = max(집합) 갱신. |
| **산출물** | 함수/메서드: `updateRepresentativeRepetitionMeta(representativeId, mergedIds, db)` 또는 워커 내 동등 로직. 단일 트랜잭션. |
| **명세 매핑** | REQ-MERGE-1, REQ-MERGE-2, UC-2. |
| **완료 조건** | 대표 ID와 병합 대상 ID 목록을 입력으로 받아, 대표의 num_times·last_mentioned_at이 갱신됨. 단위 테스트로 검증. |
