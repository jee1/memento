## 🔄 마이그레이션 단계

1. **디렉토리 생성**
   ```bash
   mkdir -p src/domains/memory/{services,repositories,tools}/__tests__
   ```

2. **파일 이동** (git mv 사용)
   - Services 파일 이동
   - Repositories 파일 이동
   - Tools 파일 이동

3. **Import 경로 업데이트**
   - 도메인 내부 import 경로 수정
   - 다른 도메인에서 참조하는 import 경로 수정
   - `src/tools/index.ts` 업데이트

4. **테스트 실행**
   ```bash
   npm test -- src/domains/memory
   ```

5. **검증**
   - 모든 테스트 통과 확인
   - TypeScript 컴파일 오류 확인
   - Lint 오류 확인

## ⚠️ 주의사항

- `src/tools/index.ts`에서 memory 도메인 tools export 경로 수정 필요
