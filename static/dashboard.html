기억 검토 후보

중요도가 높지만 오랫동안 recall되지 않은 메모리를 사람이 검토하기 위한 운영 대기열입니다. memory_review_candidates 배치가 후보를 채우고, 여기서 검토·무시로 처리합니다.

사용 방법: 목록에서 행을 선택해 미리보기에서 본문을 확인한 뒤, 검토는 검토 완료(메모리 last_accessed 갱신), 무시는 더 이상 검토할 필요 없음으로 표시합니다. 여러 행은 체크박스로 선택해 일괄 무시·만료 할 수 있습니다. 대기열 상태는 pending 적체와 최근 1시간 유입·처리량을 보여 줍니다.

대기열 상태 (#294)

롤링 윈도우는 행 타임스탬프를 사용합니다(created_at, reviewed_at, dismissed_at, expired는 updated_at 기준).

최근 샘플

샘플 시각 (UTC) 대기 순유입 1h 생성 1h 처리 1h

수동 배치 실행

이 서버 프로세스의 최근 POST /admin/batch/run 호출 (메모리 내; 재시작 시 초기화). 이슈 #295.

아직 기록된 수동 배치 실행이 없습니다.
완료 (로컬) 작업 유형 성공 소요 시간 처리 오류 / 메모
