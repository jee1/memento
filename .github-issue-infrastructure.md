## 🔄 마이그레이션 단계

1. **디렉토리 생성**
   ```bash
   mkdir -p src/infrastructure/{database,cache,scheduler}/__tests__
   ```

2. **파일 이동** (git mv 사용)
   - Database 파일 이동
   - Cache 파일 이동
   - Scheduler 파일 이동
   - 기타 infrastructure 서비스 이동

3. **Import 경로 업데이트**
   - 도메인 내부 import 경로 수정
   - 다른 도메인에서 참조하는 import 경로 수정
   - `src/database/init.ts`, `src/database/migrate.ts` 사용처 확인

4. **테스트 실행**
   ```bash
   npm test -- src/infrastructure
   ```

5. **검증**
   - 모든 테스트 통과 확인
   - TypeScript 컴파일 오류 확인
   - Lint 오류 확인

## ⚠️ 주의사항

- `src/database/` 디렉토리는 많은 곳에서 참조되므로 import 경로 수정 범위가 큼
- `npm run db:init`, `npm run db:migrate` 스크립트 경로 확인 필요
- Database optimizer tool은 MCP tools에 포함될 수 있으므로 확인 필요
