## 🔄 마이그레이션 단계

1. **디렉토리 생성**
   ```bash
   mkdir -p src/domains/relation/{services,tools}/__tests__
   ```

2. **파일 이동** (git mv 사용)
   - Services 파일 이동
   - Tools 파일 이동

3. **Import 경로 업데이트**
   - 도메인 내부 import 경로 수정
   - 다른 도메인에서 참조하는 import 경로 수정
   - Relation tools는 HTTP API로만 제공되므로 `src/tools/index.ts`에는 영향 없음

4. **테스트 실행**
   ```bash
   npm test -- src/domains/relation
   ```

5. **검증**
   - 모든 테스트 통과 확인
   - TypeScript 컴파일 오류 확인
   - Lint 오류 확인

## ⚠️ 주의사항

- Relation tools는 HTTP API로만 제공되므로 MCP tools index에는 포함되지 않음
- Relation 서비스는 remember 도구에서 자동으로 사용되므로 import 경로 확인 필요
- `src/types/relation*.ts` 파일들은 shared/types로 이동 예정 (별도 issue)
